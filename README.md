# Expense Tracker

A command-line Expense Tracker built with Python that helps users manage their daily expenses efficiently.

## Features

- Add expenses with category, description, and amount
- View all expenses with total spending summary
- Delete specific expenses
- Data stored in CSV format for persistence

## Tech Stack

- Python 3
- CSV module for data storage
- DateTime module for automatic date tracking

## How to Run

1. Clone the repository
2. Run the command: python expense_tracker.py
3. Choose options from the menu to add, view, or delete expenses

## Project Structure

expense_tracker.py - Main application file
expenses.csv - Auto-generated data file
